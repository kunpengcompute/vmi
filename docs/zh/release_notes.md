### 遗留问题

| 项目 | 内容 |
| ---- | ---- |
| 问题单号 | DTS2025120110758 |
| 严重级别 | 一般 |
| 问题描述 | 安卓 15 的 AMD 环境上，长稳高负载运行 4 天后，机器 CPU 负载异常下降，容器无法正常删除。 |
| 根因分析 | 6.6 版本内核的 amdgpu 驱动小概率发生 page fault，引发 GPU 重启，应用退出后 CPU 负载下降。其中小概率重启失败时，使用 GPU 相关资源的安卓系统进程被挂起，导致容器无法正常将其清理，容器删除失败。 |
| 影响评估 | 此问题为 6.6 内核中 amdgpu 驱动问题，从上游社区的 issue 来看，是一个普遍存在的现象，AMD 当前并未修复或给出修复计划。 |
| 规避和应急措施 | 将 Mesa 驱动替换为安卓 15 自带的 Mesa 版本无此问题。 |
| 解决计划 | 继续分析 Mesa 发布版本驱动与安卓 15 自带 Mesa 版本之间的差异，并反馈上游社区解决。 |
