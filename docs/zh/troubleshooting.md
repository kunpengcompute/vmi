# 故障案例

## 服务端数据故障处理

**现象描述**

当引擎服务端数据在编码前后出现损坏时，引擎会上报服务端数据处理失败（VMI_VIDEO_ENGINE_ENCODE_ERR）事件，用户会从 logcat 日志中看到类似的提示信息。

**对系统的影响**

当此故障发生时，引擎服务端上报事件 VMI_VIDEO_ENGINE_ENCODE_ERR 通知用户后，会继续编码并向客户端发送数据，客户端在解码损坏帧时会发生掉帧或短暂花屏（当损坏帧为 I 帧的情况下），之后会恢复正常。

**可能原因**

1. 引擎服务端抓图后发送给编码引擎的数据有损坏。
2. 编码器编码出错。

**操作步骤**

1. 在引擎生成的日志中，搜索 LOG_TAG 为 VMI_VideoEngine，级别是 error 的日志，根据日志描述确认具体的错误原因。
2. 若客户端显示出现短暂掉帧或花屏，之后恢复正常，则可继续使用。若长时间出现掉帧或花屏，则说明服务端抓图引擎或编码引擎长时间出现异常，需断开客户端连接并重新连接云手机，并检查编码器是否存在异常。
3. 若抓图引擎出现异常导致故障，则使用手机接入端重新连接云手机，业务恢复。若编码器出现异常，则解决异常后重启编码器，并使用手机接入端重新连接云手机，业务恢复。

## 服务端数据回调函数注册故障处理

**现象描述**

当引擎服务端向编码器注册数据回调函数发生异常时，引擎会上报服务端注册数据回调函数失败（VMI_VIDEO_ENGINE_REGISTER_ERR）事件，用户会从日志中看到类似的提示信息。

**对系统的影响**

当此故障发生时，引擎服务端上报事件 VMI_VIDEO_ENGINE_REGISTER_ERR 通知用户后，会继续初始化编码器。但由于数据回调函数注册失败，会导致编码器初始化失败，客户端连接断开。

**可能原因**

编码器接收数据回调函数并完成注册时发生异常。

**操作步骤**

1. 在引擎生成的日志中，搜索 LOG_TAG 为 VMI_VideoEngine，级别是 error 的日志，根据日志描述确认具体的错误原因。
2. 若编码器出现异常导致注册数据回调函数失败，则解决异常后重启编码器。
3. 手机接入端重新连接云手机，业务恢复。

当此故障发生时，引擎服务端上报事件 VMI_VIDEO_ENGINE_CONFIG_ERR 通知用户后，会继续初始化编码器。但由于编码参数配置失败，会导致编码器初始化失败，客户端连接断开。

**可能原因**

向编码器发送参数配置时发生异常。

**操作步骤**

1. 在引擎生成的日志中，搜索 LOG_TAG 为 VMI_VideoEngine，级别是 error 的日志，根据日志描述确认具体的错误原因。
2. 若向编码器发送参数配置时出现异常导致编码器设置编码参数失败，则解决异常后重启编码器。
3. 手机接入端重新连接云手机，业务恢复。
